## 📖 About The Project

**Future Champions** is a website built to raise awareness for a sports-focused NGO dedicated to supporting underprivileged youth. The platform communicates the organisation's mission, highlights its programs, and provides a way for visitors to get in touch or contribute.

This was a first-year group project applying core skills in design principles, project management, and frontend web development.

---

## 📄 Pages & Sections

- 🏠 **Home** — A compelling landing page introducing the NGO and its mission
- 🤝 **About** — The story, vision, and values behind Future Champions
- 🏅 **Programs** — Resources, training initiatives, and mentorship offerings for youth
- 📬 **Contact / Donate** — A way for visitors to reach out or support the cause
